#
#   1) pip install "whisperlivekit[qwen3-streaming]" -i <国内镜像>
#   2) pip uninstall -y torch torchaudio
#   3) pip install torch==2.13.0 torchaudio --index-url https://download.pytorch.org/whl/cu130
#
# 为什么要卸了重装：国内 PyPI 镜像默认给的是纯 CPU 轮子（torch==2.13.0+cpu），
# 装上去 whisperlivekit 会打印 "Accelerator: CPU only"，显卡完全不参与。
# 而直接 pip install 覆盖不掉——pip 只比对版本号 2.13.0，不区分 +cpu 和 +cu130，
# 会报 "Requirement already satisfied" 跳过。必须先 uninstall。
#
# 为什么是 cu130：5070 是 Blackwell (sm_120)，需要 cu128 以上；
# 但 cu128 索引最高只到 torch 2.11.0，cu129 只到 2.9.0，
# 只有 cu130 有 2.13.0，与 whisperlivekit 期望的版本一致。
# 清华的 pytorch-wheels 镜像这几个路径都是 404，官方源直连反而通畅。
